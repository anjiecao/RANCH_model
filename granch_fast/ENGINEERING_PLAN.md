# RANCH / granch_fast — engineering plan: API and test suite

*2026-09-14. Proposal for team discussion (MCF, GR, AC, RS). Branch `exact-inference-reboot`.*

## 0. Design constraints, derived from what went wrong

Every failure of the previous submission that this reboot found has a root cause that is
an *engineering* gap, and each maps to one design rule and one test that would have caught
it. This table is the specification for the rest of the document.

| # | Failure | Root cause | Design rule | Test that would have caught it |
|---|---|---|---|---|
| 1 | Grid approximation was load-bearing (ε non-collapse) | no exactness/convergence check on inference | inference is analytic; quadrature resolution is a parameter with convergence tests | posterior vs closed form (~1e-12); refine-grid invariance; golden "published-spec degeneracy" test |
| 2 | Implemented quantity (e^{−s}·KL) ≠ described quantity (EIG) | decision-variable names not tied to definitions | a registry of named decision variables, each with its formula in the docstring and an identity/brute-force test | identity `eig_code = p_concept·KL_{t+1}`; `mi` vs brute-force MI; channel sum |
| 3 | Noiseless generation vs. noisy-glimpse prose | world and learner conflated in one config (`epsilon` overloaded) | **World** (generative) and **Learner** (belief) are separate objects; the learner can never read world truth | no-oracle test: decision variables computable from observed samples only |
| 4 | Inferred-ε model produces ~no behavior under exact inference | no "does the specified model produce the phenomena?" check | specification-level behavior tests for every configuration named in the paper | phenomena matrix (habituation / dishabituation flags per configuration) |
| 5 | Infant loader included exposure-phase rows; subject key restarted per cohort | untyped, unvalidated loaders | validated loaders with schema + snapshot counts | 93 infants / 494 test trials / 15 conditions; 470 adults; unique-key assertions |
| 6 | Linking slope inverted patterns (R² is sign-blind) | unconstrained least squares | Linking is a first-class object; slope ≥ 0; signed r always reported | inverted-pattern regression: must not beat the constant baseline |
| 7 | Monte-Carlo winner's curse (grid R² .51 → .04 on re-evaluation) | selection without re-evaluation | `select(...).reevaluate(rollouts=…)` is the only way to quote an MC-selected number | synthetic-null selection test: grid max ≫ 0, re-evaluated ≈ 0 |
| 8 | "Validated reproduction" claim that no longer held; archived outputs n=92 vs 162 | no data manifest, no reproducibility script per table | hashed data manifest; every reported table regenerated by one command | manifest hash test; table-regeneration smoke |
| 9 | "Effectively deterministic" assumption in a docstring | assumptions as comments, not code | assumptions are validated config (e.g. the mean-field runner *refuses* a noisy world) | runner precondition tests |
| 10 | Implemented EIG's window is centered on the **true** stimulus | ground truth passed into the learner's computation (`z_star`) | window centering is a declared option (`observed` / `exemplar_mean` / `oracle`) and `oracle` is disallowed under noise | no-oracle test (same as #3) |

Item 10 is new: `State.step(k, z_obs, z_star)` takes the true stimulus vector as the EIG window
center. In the noiseless world `z_obs == z_star` so it is harmless; under a noisy world it is an
oracle, so the implemented functional's noisy-world numbers in the report are not strictly a
learner-computable quantity. This does not change the conclusions (the functional fails there
even with the oracle), but a shipped API must not allow it.

## 1. What exists today

**Core (≈880 lines, pure numpy/scipy, no I/O):** `analytic_core.SigmaEpsGrid` (the (σ², ε)
quadrature), `analytic_core.FeaturePosterior` (exact NIG posterior per feature given per-stimulus
sufficient statistics (n, z̄, S); posterior node weights, m_μ, v_μ), `eig.py` (KL utilities,
window-EIG terms, closed-form MI and its two channels), `metrics.State` (one learner: per-stimulus
stats + every decision variable per step), `metrics.expected_samples` (survival-product linking),
`metrics.infant_trajectories` / `adult_curves` (paradigm runners), `run_fast.FastConfig` +
`make_grid`, `linking_mixed` + `reproduce_cv` (three linkings / CV protocols).

**Drivers (≈3,500 lines):** Phase-1/2 sweeps, scorers, figure generators, Sherlock scripts. Most of
the accumulated line count; largely disposable once the API exists.

**Audit (≈1,000 lines, 13 scripts):** exactness, EIG identity, predictive semantics, MI brute force,
geometry, mean-field vs MC, ε-collapse mechanism, engine consistency. They print; they do not
assert. Converting them is the cheapest large win below.

**Performance envelope (laptop, one core):** `State.step` 0.5 ms (true EIG) to 3.4 ms (implemented
EIG, 5-point window) on a 2,400-node quadrature × 3 features; one infant trajectory (4 variables,
T=40) 150 ms; one full infant setting (480 rows × 8 rollouts) ≈ 9.5 core-min; deterministic
settings much less (plateau early-stop). Adequate for research sweeps (laptop for a study, 24-core
node for a grid). *Not* adequate for interactive/web use at scale without a batched runner: the
per-sample Python loop over features and stimuli is the cost, and vectorizing across trajectories
(same posterior algebra, stacked arrays) should give 10–50×. Measure before optimizing.

**The config smell.** `FastConfig` has 17 keyword arguments spanning prior (`mu_prior, V_prior,
alpha_prior, beta_prior`), learner noise belief (`infer_eps, mu_epsilon, sd_epsilon, eps_box`),
quadrature (`n_sigma, n_eps, sigma_box, spacing`), the EIG window (`epsilon, n_z`), paradigm
constants (`forced_exposure_max, max_observation, n_feature`) and a legacy switch (`eig_mode`).
`epsilon` alone has meant generative noise (old code), window half-width (now), and, via
`eps_box=(e,e)`, the fixed learner ε. This is exactly how failures #3 and #10 happened.

## 2. Proposed API (package `ranch`, v0.1)

Small, explicit, and structured around the world/learner split.

```python
from ranch import Prior, LearnerNoise, Quadrature, Model, World, Learner
from ranch.decision import EIG, RealizedGain, KL, Surprisal          # the registry
from ranch.paradigms import forced_exposure_then_test, self_paced, LucePolicy
from ranch.linking import Affine, SplitHalfCV, ConditionMeanCV, WithinSubject
from ranch.data import load_infant_exp1, load_adult_exp1, load_embeddings   # validated
from ranch.selection import grid_search

prior  = Prior(mu0=0.0, nu=3.0, alpha=1.0, beta=0.1)
noise  = LearnerNoise.inferred(mu=1e-3, sd=0.5)         # or LearnerNoise.fixed(0.1)
model  = Model(prior, noise, n_features=3, quadrature=Quadrature(n_sigma=80, n_eps=30))

world  = World(sigma_true=0.1, seed=7)                   # generative; World(sigma_true=0) = clean
learner = Learner(model)                                  # belief state; never sees world truth
z = world.glimpse(stimulus)                               # one noisy sample
learner.observe(stimulus_id, z)
learner.decide(EIG)                                       # forward-looking, {mu, sigma} channels
learner.decide(RealizedGain(window="observed", n_z=5))    # the paper's functional; no "oracle" under noise
learner.posterior.sigma2_eps_weights, learner.posterior.mu_moments

# paradigms return typed results (trajectories + metadata + seeds), never bare arrays
run = forced_exposure_then_test(model, world, fam=emb["cat_1"], test=emb["dog_3"],
                                exposures=8, samples_per_exposure=5, T_max=40,
                                variables=[EIG, RealizedGain, KL, Surprisal], rollouts=8)
adult = self_paced(model, world, stimuli=block, policy=LucePolicy(w=3e-5, variable=EIG),
                   mode="stochastic")                     # mode="mean_field" refuses sigma_true > 0

link = Affine(slope="nonneg")                             # r (signed) and R2 both reported
score = SplitHalfCV(link).fit(run.condition_means(), load_infant_exp1())
best  = grid_search(space, score).reevaluate(rollouts=32) # the only way to quote an MC-selected number
```

Principles behind it:

1. **World ≠ Learner.** `World` owns generative noise and the RNG; `Learner` owns beliefs. The type
   system makes failure #3 impossible: the learner has no handle on the stimulus vector, only on
   glimpses. Runner functions take both, explicitly.
2. **Decision variables are a registry with formulas.** Each class documents its definition (with
   the inference-note equation number), whether it is prospective or retrospective, and what it may
   read. `RealizedGain` exposes its window centering as an enum; the `oracle` option exists only to
   reproduce the published code and raises under a noisy world.
3. **Exactness is a contract.** `Quadrature` carries a `check_convergence()` (refine and compare) and
   the posterior has closed-form reference tests. Inference "approximations" that change behavior
   (failure #1) become test failures, not surprises.
4. **Linking and protocols are objects**, sign-constrained by default, always returning signed `r`
   alongside `R2` and the CV RMSE, with the protocol (split-half, condition-mean k-fold, within-
   subject) named rather than implied by a script.
5. **Selection knows about Monte-Carlo error.** `grid_search` returns a `Selection` whose numbers are
   unquotable until `.reevaluate()` has run on fresh seeds; the result carries both.
6. **Data are validated and versioned.** Loaders check schema, apply the test-trial filter and
   unique subject key *inside* the loader, and verify a manifest hash; any silent change to a data
   file fails the suite (failure #8).
7. **Seeds and provenance everywhere.** Every result object records model/world/paradigm config,
   seeds, package version and data manifest hash; figures and tables are regenerated from result
   objects by one command each.

Migration: `FastConfig` becomes a thin shim that builds `(Model, World)` and warns; the current
runners are re-expressed on the new objects with byte-identical golden outputs (tests in §3.7)
before the shim is removed.

## 3. Test suite

Organized by layer. "exists" = audit script to convert; "new" = to write. Tolerances are stated so
that the tests are decisive, not aspirational. Target: `pytest` in < 3 min on a laptop for the
fast set, with a `slow` marker for the statistical/MC tests (< 20 min).

### 3.1 Inference (analytic core)
- **Closed-form agreement** (exists: `test_core_exact`): posterior node weights, m_μ, v_μ vs the
  conjugate closed form for random sufficient statistics, |Δ| < 1e-10.
- **Kalman property**: v_μ given a (σ², ε) node is independent of sample *values* (shuffle values,
  keep counts) — exact equality. This is the Eq.-7 claim RS asked to verify.
- **Sufficient-statistic invariance**: sample order and chunking do not change the posterior.
- **Prior recovery**: no data → posterior equals prior; one sample → matches hand-computed update.
- **Quadrature convergence**: doubling `n_sigma`/`n_eps` changes every decision variable by < 1%
  at the reference settings; the linear-in-σ measure ⇒ effective IG(α+½, β) prior is asserted.
- **Calibration (slow)**: simulate (μ, σ², ε) from the prior and data from the model; posterior
  coverage of the truth is nominal (simulation-based calibration, rank histogram flat).
- **Golden pathology**: inferred ε + noiseless world ⇒ ε posterior mass at the lowest node > 0.99
  after 40 identical glimpses and E[samples] → 1 (the published-spec degeneracy, pinned forever).

### 3.2 Decision variables
- **Identity** (exists: `test_eig_vs_grid`, `test_pp_semantics`): implemented EIG =
  p_concept(z*)·KL_{t+1} per feature to 1e-12; concept-level (not within-stimulus) predictive.
- **Brute-force MI** (exists: `test_mi_exact`): closed-form true EIG vs numerical integration,
  < 3% relative; channels sum to the total to 1e-12.
- **Properties**: KL ≥ 0; surprisal finite; I_μ identical for familiar vs novel at equal counts
  (< 1e-6 relative); I_σ² monotone in stimulus distance over a range; every variable declines
  monotonically on repeated identical glimpses in a clean world.
- **No-oracle test** (new, from failure #10): with `World(sigma_true>0)`, every registered variable
  must be a function of observed glimpses only — computed twice with the same glimpses but a
  perturbed true stimulus, values identical. `RealizedGain(window="oracle")` is expected to fail
  this and must raise instead.
- **Symmetries**: feature permutation invariance; scale covariance of the embedding space (document
  the μ0 = 0 translation dependence as a *known* property with an explicit test, not an accident).

### 3.3 Paradigm runners
- Forced exposure adds exactly `samples_per_exposure` glimpses per exemplar slot; the test slot is
  fresh; exposure count 0 is a pure prior test.
- Deterministic plateau early-stop equals the full-length run (< 1e-6).
- Mean-field self-paced == MC average in the clean world (exists: `test_adult_meanfield`;
  tolerance 2% over 200 rollouts); mean-field **raises** for `sigma_true > 0` (failure #9).
- Stochastic Luce stopping: realized sample-count distribution matches the survival product
  (KS test, fixed seed, slow).
- Same-exemplar vs fresh-exemplar representation produce the documented one-shot vs smooth decline
  (exists: `test_same_exemplar`).

### 3.4 Linking and scoring
- **Slope constraint** (regression for failure #6): an inverted synthetic pattern scores no better
  than the constant baseline; signed r is negative and reported.
- **Split-half CV on a toy**: hand-computed RMSE/R² for a 4-condition example.
- **Condition-mean and within-subject protocols**: recover a known slope on synthetic subject data
  with random intercepts; cohort confound test (subject means differ by cohort) leaves the
  within-subject estimate unbiased.
- **Constant baselines** equal the SD of condition means (infants 4.86 s; adults 21-cond value).

### 3.5 Data
- Loader snapshot tests: infant Exp-1 → 93 infants, 494 test trials, 15 condition cells, no
  exposure-phase rows (regression for failure #5); adult Exp-1 → 470 subjects, 21/75 condition
  aggregations; embeddings 218 stimuli × 3 features; trial tables 480 rows / 20 conditions; Exp-2
  stimulus-pair tables.
- Manifest: SHA-256 of every data file the package reads, checked at import of `ranch.data`.
- Provenance guard: the archived published model output has 324 param_ids of which 92 are usable
  — pinned, with the note that published Table-1 values are not reconstructible from it.

### 3.6 Selection / Monte-Carlo hygiene
- **Winner's curse** (slow, regression for failure #7): on synthetic null data (model trajectories
  with no relation to targets), grid-search max R² over 1,000 cells at R=8 is > .3 while the
  re-evaluated R² of the selected cell is < .05 (fixed seeds).
- Re-evaluation reproducibility: same seeds ⇒ identical numbers; different seeds ⇒ within the
  reported ± (four-group SD).

### 3.7 Golden regression tables
One YAML of pinned numbers with tolerances, regenerated only by an explicit command with a diff
review: corrected-model Table-1 analogues (infants pooled R² per variable at the reference
settings), adult 21-condition R², Exp-2 carried R² and orderings, the noisy-world winners (R=32),
the configuration map (hab/dis per configuration), and the channel decomposition ratios. These are
what let the API refactor proceed without silently changing a single reported number.

### 3.8 Phenomena matrix (specification-level)
For every (world, learner-noise, decision-variable) configuration named in the report, assert the
qualitative flags the report states — habituates (familiar dur-10/dur-1 < 0.95), dishabituates
(novel/familiar at dur-10 > 1.05), degenerate (E[samples] < 1.5), inverted (novel < familiar).
This is the configuration map (figB3) as a test, and it is the single test that would have stopped
the previous submission.

### 3.9 Performance and operations
- Time budgets: `State.step` < 5 ms; one infant trajectory < 250 ms; a full setting < 15 core-min
  (fail loudly on regressions, run under `slow`).
- Thread pinning: under multiprocessing, BLAS threads = 1 (assert env) — the load-200 incident.
- Determinism: identical seeds ⇒ bit-identical trajectories across processes.
- Sherlock smoke: the three sbatch scripts run to completion on `--limit` inputs.

### 3.10 Documentation as tests
- Each decision-variable docstring cites an equation number that exists in the inference note (a
  doc-build check), and the nomenclature table in the report is generated from the registry, so the
  names in prose and code cannot drift (failure #2).

## 5. Open modeling-fidelity items the API review surfaced

1. **Oracle window** (§0 #10) — *decided 2026-09-14 (MCF): `exemplar_mean`.* One helper,
   `metrics.window_center`, serves the engine, the drivers and the API; `RealizedGain` defaults to
   `exemplar_mean`; the noisy-world drivers (`phase1_selfconsistent`, `phase1b`, `phase1c`,
   `phase1e`, `run_phase2_selfcons`, `gen_figs_channels`) take `--window` with that default;
   `oracle` remains a reproduction mode (refused by the API under noise unless
   `allow_oracle=True`). The noisy implemented-EIG rows are recomputed in
   `sherlock/window_pass.sbatch`, chained after the regeneration.
2. **`epsilon` overloading**: retire the name; window half-width becomes a `RealizedGain` argument.
3. **μ0 = 0 fixed**: the model is not translation-invariant in embedding space; embeddings are
   downscaled/centered upstream — make that an explicit preprocessing step with a test.
4. **Caps** (`max_observation`, `T_max`, 80-sample adult cap): behavioral assumptions; declare them
   on the paradigm, not the model.
5. **Quadrature boxes** (`sigma_box`, `eps_box`) act as priors; they belong in `Prior`/`LearnerNoise`
   with the convergence test guarding them.
6. **A formula slip in the closed-form true EIG, found and fixed by Phase A.** The (σ², ε)-channel
   (note eq. 15) subtracted ½·log E[vz] where the exact conditional entropy is E[½·log vz]; the
   difference is Jensen's gap = the information carried by *variance* heterogeneity across
   (σ², ε) nodes, i.e. exactly the scale-mixture term. Effect: the true EIG was underestimated
   by 3–6 % at first samples (largest at distance 0, where it was the whole σ²-channel), shrinking
   as the posterior concentrates. Adding the gap back reproduces exact numerical MI to < 0.5 %
   everywhere (the residual is the moment-matching bound). Fixed in `eig.feature_eig_channels`
   (2026-09-14); `test_decision_variables.py` now pins 1 %. **Pending (Phase B):** every
   true-EIG-dependent table and figure (infant/adult Phase-1 `mi` rows, the selfcons winners,
   Exp-2 carry, config map, channel decomposition) was produced with the old formula and must be
   regenerated with a reviewed golden-table diff; expected shifts are a few percent in the
   variable itself and smaller in the fitted R² (the gap is nearly stimulus-independent at a
   given sample count, so it slightly *compresses* novel/familiar contrast).
   **Outcome (2026-09-15):** the noiseless tables reproduced to the digit; the noisy-world
   true-EIG results collapsed (infants R² .73 → .23, dis 1.19 → 1.03; adults .68 → .27) — the
   report's finding 9 is retracted. Exact numerical MI over the full (σ², ε) mixture confirms
   the fixed closed form (≤4% bound looseness, identical novel/familiar ratios) and shows the
   old one was 20× too low for the familiar in this regime. With ε inferred, 61–97% of the
   expected information is about ε itself. A concept-only EIG (ε as nuisance), computed by
   exact quadrature, habituates 17× and dishabituates ~2×, matching what the slipped formula
   had produced: proposed as a new registered variable (`EIGConcept`) with a moment-matched
   closed form validated against the exact quadrature, then a full noisy-world study.
   The canonical-model decision (§4) is reopened.
